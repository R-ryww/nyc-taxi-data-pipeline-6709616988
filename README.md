# NYC Taxi Data Pipeline (Jan – June 2024)

## 1. ภาพรวม

งานนี้พัฒนาระบบ Data Pipeline สำหรับรวบรวม ทำความสะอาด รวม และวิเคราะห์ข้อมูลการเดินทางของแท็กซี่จาก NYC Taxi & Limousine Commission (TLC) ในช่วงเดือนมกราคม–มิถุนายน 2024

**คำถามหลัก:** แท็กซี่ประเภทใดมีจำนวนการเดินทางมากที่สุดในช่วงครึ่งแรกของปี 2024?

ข้อมูลที่ใช้ประกอบด้วยแท็กซี่ 4 ประเภท:
- Yellow Taxi
- Green Taxi
- FHV (For-Hire Vehicle)
- FHVHV (High Volume For-Hire Vehicle)

## 2. แหล่งข้อมูล

ข้อมูลจากเว็บไซต์ทางการของ NYC TLC:

https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

ใช้ไฟล์ Parquet จำนวน 24 ไฟล์ (4 ประเภท × 6 เดือน)

## 4. ขั้นตอนการทำงาน

Pipeline ประกอบด้วย 4 ขั้นตอนหลัก:

1. **Extract:** ดาวน์โหลดและตรวจสอบไฟล์ข้อมูลต้นฉบับ
2. **Transform:** รวมข้อมูลจากทั้ง 4 ประเภท ปรับชื่อคอลัมน์ให้เป็นมาตรฐาน และกรองข้อมูลให้อยู่ในช่วงเวลาที่กำหนด
3. **Quality Check:** ตรวจสอบค่าว่าง รูปแบบวันเวลา และข้อมูลนอกช่วง พร้อมเปรียบเทียบจำนวนข้อมูลกับ Curated Dataset
4. **Analysis:** นับจำนวนการเดินทาง คำนวณเปอร์เซ็นต์ และจัดอันดับแท็กซี่แต่ละประเภท

ดูแผนภาพการทำงานเพิ่มเติมได้ที่ `docs/data_flow.md`

## 5. วิธีติดตั้งและใช้งาน

**1. Clone Repository**

```bash
git clone https://github.com/R-ryww/nyc-taxi-data-pipeline-6709616988.git

cd nyc-taxi-data-pipeline-6709616988
```

**2. สร้าง Virtual Environment**

```bash
python -m venv .venv
```

เปิดใช้งานบน Windows:

```bash
.venv\Scripts\activate
```

**3. ติดตั้ง Dependencies**

```bash
python -m pip install -r requirements.txt
```

**4. เริ่มทำงาน Pipeline**

รันคำสั่งปกติเพื่อใช้ Raw Data ที่มีอยู่แล้ว (ดาวน์โหลดเฉพาะไฟล์ที่ยังไม่มีหรือไม่ผ่านการตรวจสอบ)

```bash
python -m src.pipeline
```

หากต้องการดาวน์โหลด Raw Data ใหม่ทั้งหมด ให้ใช้คำสั่ง

```bash
python -m src.pipeline --refresh
```

ระบบจะทำงานตามลำดับ Extract → Transform → Quality Check → Analysis โดยอัตโนมัติ

## 6. ผลการวิเคราะห์

ใช้จำนวน Records ที่ผ่านการตรวจสอบและอยู่ในช่วงเวลาที่กำหนดเป็นเกณฑ์วัดการใช้งาน

| อันดับ | ประเภทแท็กซี่ | จำนวน Records | สัดส่วน |
|---:|---|---:|---:|
| 1 | FHVHV | 120,864,668 | 80.76% |
| 2 | Yellow | 20,332,054 | 13.59% |
| 3 | FHV | 8,119,228 | 5.43% |
| 4 | Green | 339,801 | 0.23% |
| | **รวม** | **149,655,751** | **100%** |

**ผลลัพธ์:** FHVHV เป็นประเภทที่มีจำนวน Records มากที่สุด คิดเป็น 80.76% ของข้อมูลทั้งหมด

## 7. ผลการตรวจสอบคุณภาพข้อมูล

ผลการตรวจสอบข้อมูลทั้ง 4 ประเภท:

- ไม่มี Pickup Datetime ที่เป็นค่าว่าง
- ไม่มี Pickup Datetime ที่มีรูปแบบไม่ถูกต้อง
- พบข้อมูลนอกช่วงเวลา 45 Records (Yellow 39 และ Green 6)
- จำนวน Records ที่ผ่านเงื่อนไขตรงกับ Curated Dataset ทุกประเภท

**สถานะ: PASS ทุกประเภท**

รายงานฉบับเต็มอยู่ที่ `outputs/quality_reports/data_quality_report.csv`

## 8. การตัดสินใจในการออกแบบ

- **เลือกใช้ DuckDB:** สามารถประมวลผลไฟล์ Parquet โดยตรง เหมาะกับข้อมูลขนาดใหญ่และช่วยลดการใช้หน่วยความจำ
- **ปรับชื่อคอลัมน์ให้เป็นมาตรฐาน:** รวมชื่อ Pickup Datetime ที่แตกต่างกันให้เป็น `pickup_datetime` เพื่อให้วิเคราะห์ข้อมูลร่วมกันได้ง่าย
- **กำหนดช่วงเวลาแบบเดียวกัน:** ใช้วันที่ 1 มกราคม ถึงก่อนวันที่ 1 กรกฎาคม 2024 กับข้อมูลทุกประเภท
- **ใช้จำนวน Records เป็นเกณฑ์:** เพื่อให้เปรียบเทียบผลกับ Submission 1 ได้อย่างสอดคล้องกัน
